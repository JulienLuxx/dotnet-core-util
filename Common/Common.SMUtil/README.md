# Common.SMUtil

This project provides a utility library for SM (ShangMi) cryptographic algorithms. It is built on BouncyCastle.Cryptography and targets .NET Standard 2.0 and above. Currently, SM2, SM3, and SM4 are supported. Compatibility with the Java Hutool library has been verified through actual tests.

## Install

### .NET CLI

```bash
dotnet add package Common.SMUtil --version
```

### Package Manager

```powershell
Install-Package Common.SMUtil -Version
```
